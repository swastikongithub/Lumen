# store/

Final Google Play listing material goes here (Phase 8). Drafts and rules are in `docs/PLAY_STORE.md`.

| File | What |
|---|---|
| `listing.md` | Final app name, short and full description |
| `icon-512.png` | 512 × 512 Play icon from `design/brand/lumen-mark.svg` |
| `feature-graphic.png` | 1024 × 500 feature graphic |
| `screenshots/` | Phone screenshots from the real app (see DESIGN.md §7) |

Never put signing keys or keystore files here.
